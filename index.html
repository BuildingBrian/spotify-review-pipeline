Finding

Start with free-tier restrictions

Features locked behind Premium, such as skip limits, forced shuffle and no song choice, are the top specific issue: 9,469 complaints C1 and a severity sum of 26,088 C2. Only a catch-all bucket of generic criticism ranks higher C4, and it gives a product team nothing to act on. Billing also has more cancellation-intent reviews than any other topic.

Pipeline

Code runs the process. Models only read language.

Counting, validation, grouping and ranking are deterministic code. A model is called only where a sentence has to be read or written. Each role has its own prompt, inputs and outputs, and code checks what each one returns.

  1. 1Prepare
    Code

    Reads all 660,622 rows in 27 seconds, hashes each one, profiles the file and picks the sample. Empty texts are quarantined. No source row is dropped.

    Hands off pending review IDs
  2. 2Enrich
    Model · Claude Haiku 5.5

    Labels up to 50 reviews per request with topic, intent, severity, sentiment and an evidence quote. Code checks every field and requires the quote to be an exact substring of the review.

    Hands off validated labels
  3. 3Verify
    Model · Haiku 5.5, separate prompt

    Relabels a random 2% sample without seeing the first answer. Code compares the two and writes the disagreement report.

    Hands off verification_report.json
  4. 4Group
    Code, model names only

    Code assigns each complaint to one issue. A model only writes the plain-language issue names and cannot change membership.

    Hands off membership.csv
  5. 5Rank
    Code

    Sums severity per issue and sorts. One command rebuilds the identical ranking from saved files with no model call.

    Hands off ranking.csv
  6. 6Recommend
    Model · Claude Sonnet 5.5

    Writes the memo from the top of the ranking, topic totals and 18 representative reviews only. Code recomputes every cited number and rejects any review ID it was not given.

    Hands off memo.md + claims.csv

Guardrails that ran in the real job

  • Bounded requests. At most 50 reviews and 7,800 output tokens per call.
  • A hard spend cap. Worst-case cost is reserved before each call and work stops at $15.
  • Retry once, then quarantine. 41 records ended quarantined with a reason: 13 empty texts and 28 failed quote checks.
  • Backoff on API errors. 2 of 2,426 calls failed and were retried.
  • Reuse of identical text. 34,459 reviews reused an already validated result, with the source recorded.
  • Checkpoint and resume. Stopped on purpose at 23,096 reviews and resumed without relabeling any.

That review came after I saw the model's answers, so it is reported apart from the blind scores. Most topic misses were generic praise or criticism that I had filed under a specific topic.

Tests built to break it

  • 20 of 20 wrong labels planted in a test copy were flagged by the comparison.
  • 8 of 8 prompt-injection and edge-case reviews were handled correctly. A review saying to ignore all instructions was labeled as the crash complaint it was.
  • 9 of 9 numbers in the memo matched a recomputation from saved files, with no unknown review IDs.
  • Interrupted at 23,096 reviews and resumed. None of the finished reviews were sent to the model again.
  • Malformed output and rate limits were simulated. Bad records were quarantined and rate-limited calls were retried.

The pilot labeled 100 reviews in 61 seconds for $0.03. Rerunning it on saved results made 0 model calls.

The full run beat the forecast for two reasons: 34,459 reviews with identical text reused a validated result, and 9.3 million input tokens were read from the prompt cache at a tenth of the price.

Labeling took about 100 minutes on up to six parallel workers. Verification, grouping, ranking and the memo took 5 more.

One that failed, and what happened to it

A reviewer wrote only down side is of you want to play any song you want you'll need premium. The model's evidence quote silently corrected “of” to “if”, so it was no longer an exact substring of the source. Code rejected it, retried once and quarantined it. A later recovery pass mapped near-identical quotes back to the original characters and recovered 48 of 76 such reviews. This one stayed quarantined after three attempts and is counted as not labeled.

Role

What I did, and what the evidence cannot say

My part

  • Set the scope and chose the tools: 150,000 reviews against a 100,000 minimum, a small model for labeling, a larger one only for the memo, and a $15 spend cap.
  • Hand-labeled the 50-review test set blind, using the same written definitions the models used.
  • Judged all 28 disagreements and reported that step as after the fact.
  • Read the memo against the evidence and agreed with its recommendation before submitting.
  • Built it with Claude Code as my coding assistant.

Limits

  • These are self-selected public reviews from May 2022 to November 2023, not a sample of users.
  • There is no revenue, plan or churn data, so business impact is unknown.
  • Labels are model-assigned, at the agreement levels shown above.
  • The ranking rewards volume, which is why a catch-all sits at rank 1 and is set aside.
  • 149,972 of 660,622 reviews were labeled. The rest were ingested, profiled and hashed only.
